# 小祥画图助手 · 问题反馈

小祥画图助手（NovelAI 出图 + 客服小祥）用着出了问题，或者有想要的功能，都在这里提。

第一次用 GitHub 也没关系，照下面的步骤来就行。

## 提问题之前

1. 要有一个 GitHub 账号。没有的话点右上角 **Sign up** 注册，免费的，填邮箱和密码就行。
2. 先看看别人是不是已经报过了。点上面的 **Issues**，在搜索框里输几个关键词（比如「不回话」「出不了图」）。
   有一样的就别新开了，在那条下面回一句「我也遇到了」，顺便写上你那边的报错和时间，这样也能帮上忙。

## 怎么提

1. 点上面的 **Issues**，再点绿色的 **New issue**。
2. 选一个模板：网站出错就选「报告问题」，想要新功能就选「功能建议」。
3. 照着表单一项项填，带星号的必须填。
4. 填完点 **Create**（或 **Submit new issue**）就提交了。

有人回复的话 GitHub 会发邮件通知你。如果被问到更多情况，记得回来回一下，不然可能查不下去。

## 怎么写才查得出来

最有用的是**报错原文**。页面上弹出来的那句报错，整句复制下来贴进去，括号里的数字也要。

- 电脑上：用鼠标选中报错的字，按 Ctrl+C 复制（Mac 是 ⌘+C），到表单里 Ctrl+V 粘贴。
- 手机上：长按报错的字，选「复制」。
- 复制不了就截图。电脑上截图：Windows 按 Win+Shift+S，Mac 按 ⌘+Ctrl+Shift+4，截完直接在表单的框里按 Ctrl+V（Mac ⌘+V）就能贴进去。手机截图后，点框下面的「Paste, drop, or click to add files」把图传上去。

再写上这几样就够了：

- 当时在干嘛：点了哪个按钮、输了什么。
- 聊天用的哪个模型：在客服小祥的 **设置 → 模型 ID** 里能看到，是 DeepSeek V4 Flash 还是 Gemini 3.8 Flash High。
- 大概几点出的事，比如「北京时间 11/19 晚上 9 点左右」。
- 用的电脑还是手机，什么浏览器（Chrome、Edge、Safari……）。

一个 issue 只说一个问题。遇到好几个不一样的，就分开提。

## 举个例子

不好查的：

> - 标题：用不了了
> - 内容：小祥不理我

好查的：

> - 标题：[问题] 客服小祥发消息后报错，没有回复
> - 功能：客服小祥聊天
> - 模型：DeepSeek V4 Flash
> - 报错原文：Qwen 请求失败（429）：……（后面整段都贴上）
> - 当时在做什么：让小祥帮我写一个祥子的提示词，点了发送，转了十几秒就出了这个报错。连续试了三次都一样。
> - 时间：北京时间 11/19 21:05
> - 设备：电脑，Chrome

## 千万别贴的东西

issue 是公开的，全世界都能看到。所以**不要贴**：

- NovelAI 的 token、key，或者任何账号密码
- 自己的邮箱、手机号这类个人信息

截图里要是露出了这些，先打码再贴。

## 关于「Qwen 请求失败」

聊天出错时页面会写「Qwen 请求失败」。这是旧版本留下的名字，网站现在已经不用 Qwen 了，真正出问题的是 DeepSeek 或 Gemini。照常把整句报错贴上来就行，我们看得出是哪一个。
